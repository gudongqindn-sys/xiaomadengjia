# 篮球英语（V1 原型）

篮球主题的英语口语小程序，给一名苏州初一学生用。完整方案见 [docs/V1方案.md](docs/V1方案.md)。

本仓库和公司 ERP 完全独立：代码、数据、账号、部署都不共用。

## 现在做到哪

**阶段一：首关交互原型。** 做成手机竖屏网页，不用申请小程序 AppID 就能试玩。

- 首关「第一次训练赛」：进队自我介绍 → 听队友语音 → 两次球场配合（每次两个合理方案）→ 赛后采访 → 一个反馈点 → 领队服
- **语音是模拟的**：孩子开口说完，把他说的话打进输入框。这类记录标 `simulated`，永远不算真实口语证据
- 记录分开存：剧情进度、每次作答（提示层级、输入方式、结果）、每个目标表达的学习状态、奖励（只发一次）
- 底部导航：今日 / 球队 / 成长；家长入口在成长页底部（原型没有验证，正式版由服务端校验）

阶段二（微信真机、真实录音、语音服务）要先有 AppID、语音服务账号和孩子的手机型号，见方案最后一节。

## 画面和声音

- 卡通竞技风：原创大头角色（代码画的 SVG，在 `prototype/art.js`）、记分牌、章节开场、进球大字和彩带
- 音效现场合成，不用音频文件（`prototype/sfx.js`）：哨声、传球、进球、打框、欢呼
- 角色配音预先生成在 `audio/`：教练、Alex、Ben、Mia 各一个固定声音。改了台词要重新生成：

```bash
python3 -m venv .venv && .venv/bin/pip install edge-tts
.venv/bin/python scripts/gen_voices.py
node scripts/build.mjs
```

  用的是微软 Edge「大声朗读」的神经网络语音（非官方接口，免费、不用账号），只在原型阶段用；
  正式上线前换成腾讯云等正规语音合成服务，`audio/manifest.json` 的格式不用变。
  测试会检查每句台词都有配音文件，漏了就不过。

## 怎么试玩

最简单：电脑上双击 `dist/basketball-english.html`，用浏览器打开。手机试：把这个文件发到手机上用浏览器打开。

开发时直接用浏览器打开 `prototype/index.html` 也可以（全部是普通脚本，不需要起服务）。

## 目录

| 路径 | 内容 |
| - | - |
| `content/level-01.json` | 首关内容：角色、目标表达、意图词表、提示三层、分支、奖励。**内容唯一来源**，人工审定改这里 |
| `src/engine.js` | 规则引擎：意图匹配、作答归类、学习状态、奖励只发一次、反馈挑选。纯函数 |
| `prototype/` | 网页原型（`level-data.js`、`voice-data.js` 是生成的，不要手改） |
| `audio/` | 角色配音和 `manifest.json`（谁说哪句 → 哪个文件） |
| `scripts/gen_voices.py` | 生成配音 |
| `scripts/build.mjs` | 从 JSON 生成 `prototype/level-data.js` 和单文件 `dist/` |
| `tests/` | 引擎测试 + 内容结构检查 |

## 改内容 / 改代码之后

```bash
node scripts/build.mjs
node --test tests/*.test.js
```

内容检查会挡住这些情况：完整答案自己识别不了、某个战术方案没有能说出来的意图、新表达超过 5 个、角色没标虚构、生成文件没重新生成。

## 作答怎么归类

| 情况 | 结果 | 剧情 | 算真实口语证据 |
| - | - | - | - |
| 意思清楚、成句、没看提示 | `independent` | 推进 | 只有真实录音且识别可靠时才算 |
| 只说关键词 | `keyword` | 推进，角色给出完整句型 | 否 |
| 看了关键词 / 句型 | `with_hint` | 推进 | 否 |
| 看了完整答案 | `full_answer` | 推进 | 否 |
| 点击继续 | `click_continue` | 推进 | 否 |
| 意思不明确 | `clarify` | 角色追问，不推进 | — |
| 当前做不了（如篮下被盯） | `redirect` | 说明原因，不推进 | — |
| 和任务无关 | `off_task` | 说明缺什么，不推进 | — |
| 没听清 | `asr_uncertain` | 请孩子重说，不算错 | — |

识别服务没有给可靠度时记 `null`，不编造数字。
