篮球主题、微信小程序、与公司系统独立，已由家长确认。项目服务一名在苏州读初一、使用译林英语教材、已学完 Super Minds 3、喜欢篮球和竞技游戏的孩子。

V1 以每天约 12 分钟的单人篮球任务，帮助孩子主动开口、积累实用词汇，并在隔天的新情境中再次使用。以下时长、内容量与关卡安排作为首轮试玩参数，依据孩子表现调整。

# 产品定位与手机体验

孩子扮演球员兼队长，在自己的球队中完成试训、训练、友谊赛与赛后采访。篮球提供任务目标和行动结果，英语负责获取信息、提出请求、协调队友与解释选择。

手机优先采用竖屏布局，主要操作为点击、少量滑动和按键录音。每个小任务约 3 至 4 分钟，可以中断保存。语音交流安排在赛前、暂停和赛后，听说环节不使用催促倒计时。

角色采用原创运动形象，突出进攻、组织、防守等分工。视觉以球场、队徽、球衣和运动海报为主要元素。球员成长与队服外观让孩子感到球队属于自己。

# 每日节奏与首关

| 环节 | 建议时间 | 核心活动 |
| - | - | - |
| 热身与进入故事 | 2 分钟 | 用旧表达完成一个简单交流，明确今天的任务 |
| 获取信息与准备 | 3 分钟 | 听懂队友能力、状态或需求，完成安排 |
| 训练或短比赛 | 5 分钟 | 选择配合，暂停时沟通，执行行动 |
| 采访与收尾 | 2 分钟 | 总结一次表现、提出下次目标、保存成果 |

每日初始安排约 6 至 10 次有意义的口语回应，最多引入约 3 至 5 个新的目标词或实用短语。实际新内容由复习负担和孩子表现决定，不以固定词量强制推进。

## 第一关 第一次训练赛

场景为校园球馆。孩子与 Alex、Ben 组成三人小队，面对三名电脑对手。目标是完成两次经过沟通的配合，并在赛后介绍自己的一个选择。

### 进入球队

教练询问孩子擅长什么。先给孩子独立表达的机会，再按需要提供关键词或句型。

示例表达：I’m good at passing.

如果孩子回答顺畅，教练继续问一个简单理由或追问；如果卡住，展示关键词，再按需提供完整句型。首次任务用于观察合适难度，不输出正式等级证书。

### 了解队友

孩子分别听到 Alex 擅长传球、Ben 擅长投篮的信息。每条消息控制在一两句，可重听、慢速播放或打开字幕。

屏幕只提供需要做的决定，不在独立表达环节同时展示完整答案。孩子选择一次配合，并说明谁传球、谁接应。

可接受表达包括 Pass to Ben. 和 Let’s pass the ball to Ben. 等符合任务的自然说法。进阶时追问选择原因，例如 Because he is good at shooting.

### 沟通并行动

孩子在球场上观察位置，先作出战术选择，再向队友说明意图。队友按已经确认的意思行动，随后孩子完成一次轻量的传球或投篮操作。

同一关至少设置一个有两个合理方案的决定。语言用于说明并实现孩子自己的选择，不限制为唯一标准台词。

比赛结果结合战术选择与操作表现。系统未听清时先澄清，不把识别错误转化为丢球或扣除成长奖励。

### 赛后采访

角色询问刚才哪次配合有效，以及下一次想改进什么。

参考表达：We passed the ball well. 或 Next time, I want to shoot better.

可先说一句，也可延伸为两三句话。当天选择一个影响理解或当前目标的点反馈，避免每句话连续纠错。

### 首关成果与再次使用

首次完成后，孩子可以选择队服号码或基础配色，球队保存训练进度。奖励只发一次，重复刷同一段对话不反复增加成长值。

后续任务更换队友、站位或行动目标，再观察孩子能否独立使用同一种表达。首关过关与后续掌握分别记录。

# 英语难度与复习

Super Minds 3 作为孩子已经接触过的内容来源，具体版次与当前译林单元待用书确认。剑桥公开的第三级目录包含能力、喜好、时间、位置和建议等内容，可改编为球队生活与协作任务。课程完成经历不直接等于当前口语掌握程度。[剑桥 Super Minds 3 第二版课程目录](https://www.cambridge.org/us/files/3616/4484/9319/Scope_and_sequence_-_Super_Minds_2.pdf)

每个任务保留同一故事目标，按表现调整语言要求：

| 层次 | 支持与要求 | 示例 |
| - | - | - |
| 起步 | 必要时给关键词，表达一个清楚意思 | Pass to Ben. |
| 发展 | 自己组织短句，补充信息 | Ben is on the left. Pass to him. |
| 挑战 | 比较条件、解释理由或提出替代方案 | Ben is tired. Let’s ask Alex to play. |

能顺畅完成时减少提示并增加条件变化；反复卡住时先降低语言负担。界面与故事保持适合初一学生的风格。

词汇与表达分别记录听懂、认得、提示后能说、独立能用、间隔后仍能用。复习优先选取到期内容，并通过变化人物、物品或条件再次出现。时间间隔随表现调整，不使用固定复现次数直接宣称掌握。

主动回忆和间隔练习可用于长期记忆设计，具体安排须结合学习者与内容。它们为复习机制提供依据，不构成对这名孩子进步速度的保证。[外语词汇检索练习研究](https://pubmed.ncbi.nlm.nih.gov/18276894/) [检索与间隔因素研究](https://pubmed.ncbi.nlm.nih.gov/26674128/)

# 口语反馈与掌握记录

| 遇到的情况 | 角色反馈 | 学习记录 |
| - | - | - |
| 意思清楚，符合当前任务 | 执行动作，并给简短回应 | 记录本次可靠的独立表达证据 |
| 只说出关键词 | 先承接意思，再追问或提供句型 | 记录关键词表达及提示使用 |
| 表达与当前任务无关 | 说明还缺什么信息，允许重新表达 | 不判为目标表达成功 |
| 语义不明确 | 询问对象、数量、位置或意图 | 确认前不推进关键动作 |
| 语音识别不确定 | 承认可能没听清，允许重说或确认 | 不记录为孩子表达错误 |
| 使用完整答案或点击继续 | 保留剧情进度，后续再练 | 不记录为独立口语成功 |

录音、语音转文字、意思理解和发音评测是不同能力。V1 以沟通成功和表达支持为主，不把转写结果直接包装成精准的发音分数。

如果服务没有可靠的识别置信度，系统仍须通过歧义检测、角色确认和重试处理不确定情况，不能编造置信度。

每次练习至少保留目标表达、任务、是否使用提示、是否有效录音、识别是否可靠、本次结果和下次复习安排。经验值和游戏等级不换算为词汇量。

# 两周内容安排

两周先安排十次主任务和四个可选轻复习或休息日。每天都能进入小程序，漏一天后从已有进度继续，不补罚。下表是内容顺序，可以按家庭作息移动。

| 次序 | 任务 | 英语重点 | 复习或变化 |
| - | - | - | - |
| 第 1 天 | 第一次训练赛 | 能力介绍、提出配合 | 建立听说起点 |
| 第 2 天 | 约队友训练 | 时间、地点、邀请 | 复用自我介绍 |
| 第 3 天 | 准备训练用品 | 需求、数量、借用 | 换对象再次请求 |
| 第 4 天 | 学会空位配合 | 左右、相邻、方向 | 更换队友与站位 |
| 第 5 天 | 校园友谊赛 | 选择与简单理由 | 综合使用前四次内容 |
| 第 6 天 | 可选轻复习 | 昨天的旧表达 | 换一张球场情境 |
| 第 7 天 | 休息或分享 | 自选一段经历 | 孩子决定是否分享 |
| 第 8 天 | 队友需要休息 | 状态、饮水、建议 | 把请求用于照顾队友 |
| 第 9 天 | 调整出场安排 | 能力比较与理由 | 调用先前人物信息 |
| 第 10 天 | 训练时间冲突 | 询问、协商、替代方案 | 更换时间和条件 |
| 第 11 天 | 制订个人训练计划 | 目标、频率与计划 | 使用已有时间表达 |
| 第 12 天 | 小队综合挑战 | 沟通、选择、调整 | 使用新条件检查迁移 |
| 第 13 天 | 可选生活任务 | 借文具或约活动 | 将球队表达用于日常生活 |
| 第 14 天 | 休息或赛季回顾 | 自选总结与下次目标 | 比较提示是否减少 |

每次主任务设一到两种主要表达功能。目标词优先来自孩子当前学习内容和日常通用表达，少量加入篮球词汇；不让专业战术术语挤占实用语言。

# 奖励与使用节奏

- 用队服配色、号码、队徽、章节成果和新场景提供明确奖励。

- 用会邀请队友、会说明位置、会解释选择等能力名称展示成长。

- 通过固定角色与前后关联的故事，让每次行动留下结果。

- 每次任务有自然结束点，离开后保存进度，重新进入可继续。

- 采用每周约五次主任务的弹性目标，休息不会清零已获得成果。

- 单人 V1 使用确定奖励，不加入真实陌生人匹配、付费战力或随机抽卡。

家长每周可以邀请孩子分享一段愿意展示的经历，主要观察表达和自主参与。练习录音不作为公开排名素材。

# 内容与数据组织

关卡内容采用人工可审阅的数据结构，包含故事目标、可用角色、目标词句、可接受的沟通意图、提示层级、合理分支、结束条件和奖励。

AI 可以草拟对话与识别不同说法。进入孩子可玩的内容库前，核对英语自然程度、难度、任务条件与答案是否一致。关键通关条件、奖励和复习更新由明确规则控制。

学习数据按孩子独立保存，至少区分：

- 任务记录：完成与中断状态、使用时长、当前剧情位置。

- 练习证据：目标项、提示程度、语音或点击方式、识别可靠性。

- 学习状态：听懂、认得、独立表达证据及下次复习时间。

- 游戏状态：角色、队服、章节和已经发放的奖励。

- 家长设置：每次时长、录音保留与样本删除。

原始录音处理后默认删除；家长和孩子主动选择的成长片段另行保留，并提供删除入口。接入语音服务前核对服务侧的数据留存设置。

# 开发顺序与验收

## 阶段一 形成首关交互原型

完成今日入口、首关故事、位置选择、短动作反馈、提示层级和收尾。模拟语音状态必须清楚标注，不将点击操作记为真实口语。

验收重点：孩子知道目标，愿意作出选择，看得懂结果，任务有自然结束点。

## 阶段二 打通微信真机首关

在独立小程序项目中接入真实录音、音频播放、语音服务和任务状态保存。验证手机系统、微信版本、网络变化、拒绝授权、无声录音、中断和重试。

验收重点：合理的多种说法可以推进任务；系统误听可以恢复；提示、点击与独立语音分别记录；重复提交不重复发放奖励。

## 阶段三 扩展两周内容

加入其余主任务、跨天复习、角色成长和家长周报。复用已有场景和任务机制，通过人物、条件和目标变化形成新内容。

验收重点：孩子在新鲜感减弱后仍愿意参与，提示使用有机会逐步减少，隔天换情境能再次使用已练表达。

## 首轮验收记录

- [ ] 首关在约定时长内自然结束，并能中断后继续。

- [ ] 存在至少一个有两种合理选择的任务，表达能影响行动。

- [ ] 不同的正确说法可以得到恰当回应。

- [ ] 识别不确定、拒绝录音或网络中断时不会卡死或误扣进度。

- [ ] 看完整答案和点击确认不会被计为独立口语成功。

- [ ] 几天后更换人物或条件，能够再次观察相同目标表达。

- [ ] 家长页面能够区分参与、提示使用和独立表达。

- [ ] 学习数据、登录与部署完全独立于公司系统。

两周用于检查可玩性与明显问题，之后继续观察稳定使用和跨场景表达。上述目标是验收方向，不是已测得的效果或提分承诺。
